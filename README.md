# Monster PvP

Тактическая карточная игра для двух игроков в браузере — **Огонь против Воздуха**. Собери команду из трёх монстров и колоду способностей, создай арену из территорий и победи соперника в пошаговых сражениях на поле 2 × 3.

В игре доступны 10 монстров, 120 карт, конструктор колод, коллекция и комнаты для игры с другом. Сервер написан на Python и Flask, интерфейс — на HTML, CSS и JavaScript.

## Как запустить

Нужен **Python 3.10+**. Скачай репозиторий и распакуй его или клонируй:

```bash
git clone https://github.com/kuistal/monster_pvp_playtest.git
cd monster_pvp_playtest
```

**Windows:** запусти `start_windows.bat`.

**Linux / macOS:** открой терминал в папке проекта и выполни:

```bash
sh start_linux_mac.sh
```

Скрипт установит Flask, если он ещё не установлен. Для первой установки нужен интернет.

Также можно запустить вручную:

```bash
python -m pip install -r requirements.txt
python app.py
```

На Linux / macOS используй `python3` вместо `python`.

Открой **http://127.0.0.1:5000**. Чтобы остановить сервер, нажми `Ctrl+C` в терминале.

## Как играть с другом

1. Первый игрок нажимает «Создать комнату» и получает код — он играет за Огонь.
2. Второй открывает тот же сервер и вводит код комнаты — он играет за Воздух.
3. Колоды можно подготовить в разделе «Мои колоды», правила доступны внутри игры.

На другом компьютере в той же локальной сети открой `http://IP_КОМПЬЮТЕРА_С_СЕРВЕРОМ:5000`. Для проверки вдвоём на одном компьютере используй разные браузеры или обычное и приватное окна.

> Это прототип для закрытых плейтестов: некоторые эффекты требуют ручной обработки. Комнаты исчезают после перезапуска сервера, а колоды сохраняются в браузере. Запускай игру в доверенной локальной сети.
