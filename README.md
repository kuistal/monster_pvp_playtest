## Что изменилось в v0.26

- Все 30 пробуждённых способностей можно выбрать в редакторе колод, сохранить, разыграть в матче (в рамках тестовых механик); блокировка снята на клиенте и сервере.
- Для тестирования **пробуждённые карты доступны с начала матча**, а не после прокачки. Это временный режим: условие пробуждения и прибавки CP/атаки ещё не формализованы. При использовании пробуждённой способности портрет монстра переключается на пробуждённую форму **только визуально**, без изменения базовых характеристик.
- Колода по-прежнему состоит из 21 карты: 15 способностей и 6 территорий. Для каждого монстра нужно выбрать 3 разные способности, до 5 физических копий; максимум 2 одинаковые копии. Нейтральных карт можно включить максимум 3.
- Пробуждённые карты поддерживают целевые и массовые эффекты. Для эффектов с перемещением сначала выбирается монстр, затем территория назначения. Реакции срабатывают только в окне события, за 0 ОД: отмена принудительного перемещения, защита от обычной атаки и пробуждённая реакция Сильфиды на горение в конце хода.
- Поле, жетоны, боковые панели и рука используют единую тему «Runic Basalt + Compact HUD» из v0.25. На стандартных мониторах поле и рука расположены без общей прокрутки.

## Ограничения

- Это тестовый прототип, не полная реализация GDD. Не все обычные и нейтральные карты автоматизированы; часть сложных эффектов по-прежнему требует инструментов ведущего. Реакции на урон обрабатываются для обычных атак, включая бесплатную атаку при столкновении. Для некоторых других источников урона отдельные окна реакции пока не созданы.
- Реакция Сильфиды «Последний порыв» автоматизирована для горения в конце хода; обработка других негативных эффектов пока не реализована.
- Возрождение/прокачка и дополнительные CP/атака пробуждённой формы не реализованы, поскольку параметры пока не определены.
- Комнаты хранятся в оперативной памяти и пропадают после перезапуска сервера. Не предназначено для открытого интернета без дополнительной защиты.

# Monster PvP — Playtest 0.3

Локальный Flask-прототип для двух реальных игроков с одной общей комнатой. Огонь против Воздуха.

## Запуск Windows

1. Установить Python 3.10+ и отметить «Add Python to PATH».
2. Распаковать ZIP.
3. Запустить `start_windows.bat` либо в терминале:

```bash
python -m pip install -r requirements.txt
python app.py
```

4. Открыть `http://127.0.0.1:5000`.
5. Нажать «Создать комнату» и передать код второму игроку.
6. Для игры на другом компьютере в той же локальной сети открыть `http://IP_КОМПЬЮТЕРА_С_СЕРВЕРОМ:5000`. Файрвол Windows может запросить разрешение доступа для Python. Внешний интернет-доступ без VPN/сети вроде Tailscale или размещения на сервере не настроен.

## Что есть

- 6 монстров, официальные для текущего проекта концепт-арты из пользовательского GDD; есть изображения пробуждённых форм в `static/img`.
- Каталог 60 способностей (30 обычных + 30 пробуждённых) и 12 территорий. Карточные эффекты в части воздушных карт и в пробуждённых формах — **тестовые варианты**, не окончательно принятые правила.
- Две тестовые колоды по 21 карте; стартовая рука 3 способности + 1 территория; муллиган однократно; добор 1 из 2, начиная со второго собственного хода; одна карта при остатке одной.
- Поле 2×3, размещение территорий, призыв, отзыв, 2 ОД, обычные атаки, базовая бесплатная атака при вступлении в столкновение, очки, горение в конце собственного хода, завершение обычных и массовых боёв.
- Комнаты для 2 устройств с общим состоянием и раздельной приватной рукой каждого игрока, журнал действий, панель ручных изменений CP, горения, защиты и атаки.

## Ограничения playtest-версии

- **Не готовая игра и не полный арбитр правил.** Сложные карты разыгрываются с ручным применением эффекта в панели. Реакции пока без автоматического 10-секундного окна. Входные/пассивные эффекты территорий и монстров не все автоматизированы. Добор и его состояние синхронизированы между двумя игроками.
- Параметры на картах воздуха и пробуждённых способностях местами предварительные. У пробуждённых монстров пока нет согласованных CP/ATK; в бою используются обычные формы.
- Ручное принудительное притяжение является отдельным демонстрационным действием за 1 ОД (не автоматизирует конкретную карту).
- В прототипе карта при разыгрывании отправляется в сброс, **но её текстовый эффект не применится сам**. Учитывайте это в ходе тестирования.
- Нет авторизации, рейтингов, базы данных и сохранения комнат между рестартами. Для закрытого тестирования, не для открытой публикации в интернет.
- Карты с выбором и перемещением между территориями требуют ручного контроля. Система не заменяет ведущего теста.
- Муллиган: повторно взятые карты соответствуют тому же типу (способность/территория), как в правилах; конкретная физическая копия может вернуться.
- Размер руки в конце хода максимум 4. Если карт больше, игра просит уменьшить руку; интерфейс сброса сверхлимита пока не сделан.

## Архитектура

- `app.py`: Flask API и игровое состояние (пока in-memory).

- `templates/index.html`, `static/style.css`, `static/app.js`: интерфейс.
- `static/img/*.webp`: изображения, извлечённые из предоставленного GDD.

## Изменения версии 0.2

- Карты в руке теперь сначала выбираются, затем цель выбирается на поле. Кнопка «Применить карту» используется для способностей без цели. Карты больше не списываются при случайном нажатии.
- Сервер автоматически применяет обычные удары, ряд атакующих способностей, бонусы атаки, лечение, щиты, наложение и очищение горения, «Огненный призыв», особенности Игниса и Магмора, огненные территории и массовое завершение боёв.

- Способности, для которых реализация не утверждена или ещё не сделана, показывают сообщение и НЕ списывают карту; их можно проводить с ведущим вручную.
- Данные комнат сохраняются в оперативной памяти процесса Flask и исчезают при его перезапуске. Версия рассчитана на небольшие закрытые плейтесты, не на публичный сервер.

### Известные ограничения версии 0.2

1. Реализована только часть сложных эффектов; неавтоматизированные карты отклоняются без списания, для них нужны согласованные правила либо дальнейшая разработка.
2. Специальные карты реакции на урон, кроме «Обратного порыва» для перемещения, ещё не имеют отдельного окна реакции.
3. Ряд бонусов и активных способностей не полностью отслеживает длительности в раундах.
4. Текстовые эффекты воздушных территорий ещё не утверждены и не включены в автоматический движок.
5. Прототип использует тестовые наборы карт и обычные формы; редактора колод и пробуждения во время боя пока нет.
6. Приложение следует запускать в доверенной локальной сети. Для игры через Интернет нужен отдельный безопасный сервер и учётные записи.

## v0.5: Редактор колод

Кнопка **«Мои колоды»** открывает конструктор в стиле Hearthstone:
- слева коллекция с поиском и фильтрацией по стихии, монстру, типу;
- справа текущая колода с миниатюрами, количеством копий и кнопкой удаления;
- нажатие на карту добавляет экземпляр, двойное нажатие открывает увеличенное изображение;
- можно создавать, копировать, переименовывать, сохранять, удалять колоды и выбирать активную;
- сохранение выполняется в `localStorage` текущего браузера. Для другого устройства надо собрать/сохранить колоду отдельно.

**Ограничения для стандартного плейтеста**: 21 карта, 15 способностей и 6 территорий, 3 разных обычных способности каждого из трёх монстров, распределение копий `2 + 2 + 1` (5 карт каждого монстра), не более двух копий одной территории. Пробуждённые способности видны, но недоступны для этого формата. После выбора колоды она передаётся на сервер при создании комнаты (Огонь) или присоединении (Воздух), сервер повторно проверяет правила. Уже начавшийся матч не изменяется после правки колоды. Если нет выбранного кастомного варианта, используется стартовая сборка.

Зависимости и запуск остались прежними: `start_windows.bat` / `pip install -r requirements.txt`, затем `python app.py`.
