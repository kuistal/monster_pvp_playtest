# UI Kit v0.22: Runic Basalt / Compact HUD

## Принцип
Сдержанная фактура тёмного базальта, холодная сталь, бронза только на основных действиях, немного стихийных цветов. Интерфейс в 2.5D через рельеф, рамки и тени; никакой 3D-геометрии и тяжёлых эффектов.

## Реализация
- `static/ui/v22/`: 34 независимых визуальных ассета (SVG и WebP).
- `static/ui-theme-v22.css`: дополнительный слой темы поверх исходного `static/style.css`. Его можно отключить без изменения игровой механики.
- Базальтовые текстуры используются в доске и крупных панелях.
- Кнопки, рамки клетки, жетоны, рунический символ пустого слота и иконки статусов имеют отдельные файлы; все подписи, CP, стоимость ОД, эффекты карт берутся из данных приложения.
- Существующие иллюстрации карт и монстров не изменялись.
- Компоновка поля и центрированной руки v0.21 сохранена.
- Для отключения лишней анимации поддерживается `prefers-reduced-motion`.

## Приоритет UX
1. Поле и рука в одном экране на десктопе без скроллинга страницы.
2. Выбранные цели, реакции и отрицательные состояния считываются без декоративного шума.
3. Меню, коллекция, правила и сборщик колод остаются кликабельными, текст - HTML.
4. Кнопки доступны с клавиатуры. На маленьких экранах детали прокручиваются внутри своих панелей.

## Ограничения
- UI проверялся браузерным тестом с имитацией данных состояния матча, без полноценного сетевого плейтеста Flask.
- Некоторым мелким текстам в компактном режиме 1280×720 ещё требуется доработка для соответствия строгой планке доступности (≥13 px), поэтому арена и рука проектировались с приоритетом размещения и отсутствия перекрытий.
